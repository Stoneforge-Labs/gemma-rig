# Gemma Rig

Measured serving, evaluation, and agent-workflow results from running Gemma 4
models on one RTX 5090.

[Read the report](https://stoneforge-labs.github.io/gemma-rig/)

The report records successful configurations, failed experiments, benchmark
results, and the harness bugs found along the way. It is published first while
the reusable harness code is separated from unrelated private code.
